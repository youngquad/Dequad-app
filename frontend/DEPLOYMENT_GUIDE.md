# 🚀 Educare App - TestFlight & Google Play Deployment Guide

This guide will walk you through deploying Educare to **TestFlight (iOS)** and **Google Play Internal Testing (Android)**.

---

## 📋 Prerequisites Checklist

Before you begin, ensure you have:

- [x] Apple Developer Account ($99/year)
- [x] Google Play Developer Account ($25 one-time)
- [ ] Expo account (free) - Create at https://expo.dev
- [ ] EAS CLI installed on your computer
- [ ] Node.js 18+ installed

---

## 🛠️ Step 1: Download Your Code

First, download your Educare app code from Emergent:

1. Click the **"Save to GitHub"** button in Emergent
2. Clone the repository to your local computer:
   ```bash
   git clone https://github.com/YOUR_USERNAME/educare.git
   cd educare/frontend
   ```

---

## 🔧 Step 2: Set Up Expo & EAS CLI

### Install EAS CLI globally:
```bash
npm install -g eas-cli
```

### Log in to your Expo account:
```bash
eas login
```

### Link your project to Expo:
```bash
cd frontend
eas init
```

This will:
- Create a project on Expo's servers
- Generate a unique `projectId`
- Update your `app.json` automatically

---

## 📱 Step 3: Configure for Production

### Update `app.json` with your details:

Open `frontend/app.json` and update these fields:

```json
{
  "expo": {
    "owner": "YOUR_EXPO_USERNAME",
    "extra": {
      "eas": {
        "projectId": "YOUR_PROJECT_ID"  // Auto-generated by eas init
      }
    }
  }
}
```

### Update `eas.json` with your credentials:

Open `frontend/eas.json` and update:

```json
{
  "submit": {
    "production": {
      "ios": {
        "appleId": "your.email@example.com",
        "ascAppId": "1234567890",  // From App Store Connect
        "appleTeamId": "ABCD1234"  // From Apple Developer Portal
      },
      "android": {
        "serviceAccountKeyPath": "./google-services.json",
        "track": "internal"
      }
    }
  }
}
```

## 🍎 Step 4: iOS - TestFlight Setup

### 4.1 Create App in App Store Connect

1. Go to [App Store Connect](https://appstoreconnect.apple.com)
2. Click **"My Apps"** → **"+"** → **"New App"**
3. Fill in:
   - **Platform**: iOS
   - **Name**: Educare
   - **Primary Language**: English
   - **Bundle ID**: `com.educare.wellbeing`
   - **SKU**: `educare-wellbeing-001`
4. Click **"Create"**
5. Note down the **Apple ID** (found under App Information)

### 4.2 Get Your Apple Team ID

1. Go to [Apple Developer Portal](https://developer.apple.com/account)
2. Click **"Membership"**
3. Copy your **Team ID** (e.g., `ABCD1234XY`)

### 4.3 Build for iOS

```bash
cd frontend
eas build --platform ios --profile production
```

This process takes ~15-30 minutes. You'll be prompted to:
- Log in with your Apple ID
- Generate certificates (select "Yes" for auto-generation)

### 4.4 Submit to TestFlight

```bash
eas submit --platform ios --profile production
```

Or submit automatically after build:
```bash
eas build --platform ios --profile production --auto-submit
```

### 4.5 Set Up TestFlight Testers

1. Go to App Store Connect → Your App → **TestFlight**
2. Click **"Internal Testing"** → **"+"**
3. Create a group (e.g., "Beta Testers")
4. Add testers by email
5. Once the build is processed, testers receive an email invitation

### 4.6 Share TestFlight Link

After your build is approved (usually within 24 hours):
1. Go to TestFlight → Your build
2. Click **"Public Link"** → Enable
3. Share the link: `https://testflight.apple.com/join/XXXXXXXX`

## 🤖 Step 5: Android - Google Play Setup

### 5.1 Create App in Google Play Console

1. Go to [Google Play Console](https://play.google.com/console)
2. Click **"Create app"**
3. Fill in:
   - **App name**: Educare
   - **Default language**: English
   - **App or game**: App
   - **Free or paid**: Free
4. Accept policies and click **"Create app"**

### 5.2 Create Service Account for EAS

1. Go to Google Play Console → **Setup** → **API access**
2. Click **"Create new service account"**
3. Follow the link to Google Cloud Console
4. Create a service account with these permissions:
   - **Role**: Service Account User
5. Download the JSON key file
6. Rename it to `google-services.json`
7. Place it in your `frontend` folder
8. Back in Play Console, grant the service account **Admin** access

### 5.3 Build for Android

```bash
cd frontend
eas build --platform android --profile production
```

This generates an `.aab` (Android App Bundle) file.

### 5.4 Submit to Google Play

```bash
eas submit --platform android --profile production
```

### 5.5 Set Up Internal Testing

1. Go to Google Play Console → Your App → **Testing** → **Internal testing**
2. Click **"Create new release"**
3. Upload your `.aab` file (or use EAS submit)
4. Add release notes
5. Click **"Save"** → **"Review release"** → **"Start rollout**

### 5.6 Add Testers

1. Go to **Internal testing** → **Testers**
2. Create a new email list
3. Add tester emails
4. Copy the **"Join on the web"** link to share

## 🔧 Troubleshooting

### iOS Build Fails
- Ensure Bundle ID matches App Store Connect
- Check Apple Developer membership is active
- Verify certificates in Apple Developer Portal

### Android Build Fails
- Ensure package name matches Play Console
- Check `google-services.json` is valid
- Verify service account has correct permissions

### Submission Rejected
- Add required privacy policy URL
- Complete all required store listing fields
- Ensure app icons meet size requirements

## 📱 App Store Requirements

### iOS (Required before public release):
- Privacy Policy URL
- App screenshots (6.5" and 5.5" displays)
- App description
- App icon (1024x1024)
- Support URL
- Age rating

### Android (Required before public release):
- Privacy Policy URL
- App screenshots (phone + tablet)
- Feature graphic (1024x500)
- App icon (512x512)
- Short & full description
- Content rating questionnaire
