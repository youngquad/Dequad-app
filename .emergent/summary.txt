**original_problem_statement**:
The user wants to build a comprehensive, full-stack AI-powered mobile application called Educare for student wellbeing and engagement.

**PRODUCT REQUIREMENTS:**
- **Platform:** Expo (React Native) mobile app.
- **Authentication:** User login/registration. A dedicated admin login page is also required.
- **Core Mobile Features:**
  - Mood tracking (rating 1-10) and text-based lecture feedback.
  - Tinder-style swipe UI for student matching.
  - Real-time, encrypted chat between matched students.
  - Student profile page with editable preferences.
  - Ability for students to upload up to 3 profile pictures.
- **Subscription Model (Stripe):**
  - Implement a Premium subscription tier.
  - Free users have a daily swipe limit on the matching feature.
  - Premium users have unlimited swipes.
  - The subscription management/upgrade option should be accessible from the user's profile screen.
- **Safeguarding Features:**
  - Implement a safeguarding matrix in mood, feedback, and chat functions.
  - If a user's text contains high-risk keywords (e.g., kill myself), the app should display a modal with crisis resources (Samaritans, 999, etc.).
  - An alert should be generated and made visible to admins.
- **AI/Backend Features:**
  - Use an LLM to analyze mood and feedback for at-risk prediction. This analysis must be an admin-only feature.
- **Admin Features:**
  - A web-based admin dashboard accessible via a separate login.
  - **Dashboard Overview:** Display total student count, subscribed student count, and a breakdown of students per university.
  - **Analytics:** Visual charts for mood trends, engagement, and risk distribution.
  - **Data Export:** Admins must be able to export user data, feedback, and alerts as CSV files.
  - **University-based Analysis:** Admins must be able to filter data and run analysis for all students in a specific university.
  - **Individual Analysis:** Admins must be able to trigger an AI analysis for individual students directly from the dashboard (e.g., from a safeguarding alert).

**User's preferred language**: English

**what currently exists?**
The project is a feature-rich, full-stack application using Expo (React Native) for the frontend and FastAPI/MongoDB for the backend. Nearly all user-requested features have been implemented, including:
- Full user and admin authentication.
- A sophisticated, multi-tabbed admin dashboard with charting, data export, and university-based filtering.
- A complete Stripe subscription system that limits swipes for free users.
- A robust safeguarding system that detects high-risk language in user inputs (mood, feedback, chat) and displays a crisis resource modal.
- AI risk analysis functionality is restricted to admins.
