# DEQUAD App Store media

This folder contains two English (U.K.) App Store screenshot sets:

- `iphone-6.5`: five 1284 × 2778 px portrait screenshots.
- `iphone-6.9`: five 1320 × 2868 px portrait screenshots for current flagship
  iPhones.
- `ipad-13`: five 2064 × 2752 px portrait screenshots.
- `ipad-13-2048x2732`: alternate five-file iPad portrait set for App Store
  Connect upload compatibility.

The sets are ordered so the first three communicate DEQUAD's core experience on
the installation sheet:

1. Find verified student connections.
2. Track daily mood and wellbeing.
3. Chat safely with matches.

Upload each PNG set in filename order. Apple currently lists 1320 × 2868 under
the **6.9-inch iPhone display**, 1284 × 2778 under the **6.5-inch iPhone
display**, and 2064 × 2752 or 2048 × 2732 under the **13-inch iPad display**.
Apple Watch and iMessage media are not included because this repository does
not contain Watch or iMessage targets.

Run the matching `generate_*_screenshots.sh` script from this folder to
regenerate a set from the repository's mobile UI captures.
